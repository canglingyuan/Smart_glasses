## 作品简介

为解决视障人士出行避障难、路口通行无保障的核心痛点，本作品基于 STM32U5 低功耗旗舰 MCU，协同 OpenMV 视觉协处理器，打造一款轻量化 AI 智能助盲眼镜。系统以 STM32U5 为控制核心，通过摄像头实时采集环境画面，运行 10 项边缘视觉检测算法——包括红绿灯识别（含 50Hz 电网闪烁检测排除车尾灯/广告牌干扰）、斑马线检测、障碍物检测、坑洞/凸起识别、上下楼梯判断、头顶障碍物检测、盲道视觉追踪（AI 模型识别盲道纹理 + 方向引导）——实现全面环境感知。同时融合 ToF 8x8 面阵激光测距、超声波、MPU6050 六轴姿态，配合连续置信度衰减模型和五级传感器状态机——传感器短暂断联不立即报警，而是逐步降低信任度，仅硬件真故障才触发提醒——有效消除抖动误报。识别结果通过 SYN6288 中文语音合成芯片实时播报，引导用户安全通行。方案充分发挥 STM32U5 的低功耗后台自主采集技术，配合 L1/L2/L3 三级动态功耗切换，在保证实时性的同时大幅延长续航。作品从"感知—融合—决策—交互"全链路出发，为视障群体提供了一套实用、可靠、低成本的智能出行辅助方案，兼具社会价值与技术前瞻性。

## 核心指标

| 指标 | 数值 |
|------|------|
| 视觉检测项 | 10 项 |
| 检测帧率 | 30 FPS (QVGA 320x240) |
| 端到端延迟 | < 100 ms |
| 传感器量程 | 1-200 cm (ToF) + 200-400 cm (超声) |
| 功耗等级 | L1/L2/L3 三级动态 |
| 语音 | SYN6288 中文 TTS |
| 代码规模 | OpenMV ~11个.py / STM32 ~13个.c |
