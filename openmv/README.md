# 智能助盲眼镜 v7.0 (初赛版)

> **作品简介：** 为解决视障人士出行避障难、路口通行无保障的核心痛点，本作品基于 **OpenMV H7 Plus + STM32U5 双 MCU 异构架构**，打造一款轻量化 AI 智能助盲眼镜。系统采用 OpenMV 视觉模块以 30FPS 实时采集环境画面，运行 **10 项边缘视觉检测算法**——包括红绿灯识别（含 50Hz 电网闪烁检测排除车尾灯/广告牌干扰）、斑马线检测、障碍物检测、坑洞/凸起识别、上下楼梯判断、头顶障碍物检测、盲道视觉追踪（AI 模型识别盲道纹理 + Hough 方向引导）——实现全面环境感知。同时 STM32U5 端融合 **ToF 8×8 面阵激光测距、超声波、MPU6050 六轴姿态**，配合独创的**连续置信度衰减模型**和**五级传感器状态机**——传感器短暂断联不立即报警，而是逐步降低信任度，仅硬件真故障才触发提醒——有效消除抖动误报。识别结果通过 **SYN6288 中文语音合成芯片**实时播报，引导用户安全通行。方案充分发挥 STM32U5 的 **LPBAM 低功耗后台自主采集技术**，配合 **L1/L2/L3 三级动态功耗切换**，在保证实时性的同时大幅延长续航。作品从"感知—融合—决策—交互"全链路出发，为视障群体提供了一套实用、可靠、低成本的智能出行辅助方案，兼具社会价值与技术前瞻性。

## 硬件架构

```
┌──────────────┐     UART(115200)      ┌──────────────┐
│  OpenMV H7+  │ ◄────────────────── ► │   STM32U5    │
│  (视觉+决策)  │    RED/GREEN/ZEBRA... │  (传感器Hub)  │
└──────┬───────┘                       └──────┬───────┘
       │                                      │
   OV7725 摄像头                      ┌───────┼───────┐
                                      │       │       │
                                   ToF     超声波    MPU
                                 (VL53L) (HC-SR04) (MPU6050)
                                      │
                                  SYN6288 TTS
                                   + 3W 扬声器
```

| 组件 | 连接 | 用途 |
|------|------|------|
| OpenMV H7 Plus | 主板 | 图像采集、视觉检测、决策 |
| STM32U5 | UART3 | 传感器采集、语音播报、OLED、按键、LED |
| ToF VL53L5CX | STM32U5 I2C | 8×8 面阵地面测距 (1-200cm) |
| 超声波 HC-SR04 | STM32U5 GPIO | 前方长距 (200-400cm) + 头顶 |
| MPU6050 | STM32U5 I2C | 姿态检测 + 跌倒 |
| SYN6288 | STM32U5 UART2 | 中文语音合成 |
| OLED 0.96" | STM32U5 I2C | 状态显示 |

## 检测能力

### 10 项视觉检测

| 检测项 | 方法 | 输出 |
|--------|------|------|
| 红绿灯 | LAB + A通道二次验证 + 50Hz闪烁CV | red / green |
| 斑马线 | 白色阈值 + Hough线 + 条纹等宽验证 | crosswalk |
| 大型障碍物 | 暗色blob + 纹理过滤 + 距离面积缩放 | obstacle |
| 中距障碍物 | 同上，较低面积阈值 | obstacle_near |
| 坑洞 | ToF距离突变 + 边缘梯度 | pothole |
| 路面凸起 | 同上反向 | bump |
| 楼梯 | Hough线密度 + ToF地面距离趋势 | stairs_up / stairs_down |
| 头顶障碍 | 暗色blob + 超声波 <80cm 双重确认 | overhead |
| 横向拦截物 | 水平长线段检测 | lateral |
| 盲道追踪 | CNN二分类(tflite) + Hough方向判断 | tactile_direction |

### 优先级仲裁 (P0-P4)

```
P4 - 红灯 / 头顶障碍物      ← 紧急
P3 - 坑洞/凸起/大型障碍物/拦截物/下楼梯
P2 - 盲道偏离/中距障碍物
P1 - 斑马线/上楼梯
P0 - 绿灯/转弯建议           ← 信息
```

## 核心创新点

1. **50Hz 闪烁检测** — CV变异系数区分交流红绿灯 vs DC光源
2. **连续置信度衰减** — 替代二值超时判断，消除传感器抖动误报
3. **五级传感器状态机** — OK→STALE→DEGRADED→TIMEOUT→DEAD，连续3次超时才判故障
4. **软投票（设计理念）** — 加权评分替代一票否决，避免单传感器失效触发误报
5. **ToF自适应基线校准** — 前100帧自动学习基线，慢速EMA跟踪温漂，30cm上限钳制
6. **视觉盲道追踪** — CNN(3857参)+Hough线替代传统颜色传感器，输出方向引导
7. **时序滤波消抖** — 5帧多数投票+迟滞，帧间跳跃率从23%降到3%
8. **距离自适应面积缩放** — 面积阈值跟随测距动态调整 (0.3~1.5×)
9. **L1/L2/L3三级功耗** — 15s降频 → 30s深睡眠，按键/姿态唤醒

## 快速开始

1. OpenMV IDE → 连接 → 按 `config → sensors → fusion → battery → vision → interaction → power → decision → stats → glasses → main` 顺序烧录
2. STM32U5 烧录 `V0.1_LED` 固件
3. 上电 → 观察 LED 自检闪码 → 绿灯长亮进入主循环
4. 串口 115200 查看实时检测日志
